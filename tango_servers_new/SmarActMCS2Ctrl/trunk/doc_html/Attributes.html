ExternalSyncRate false false Scalar READ_WRITE Tango::DEV_LONG OPERATOR External stream synchronization rate in Hz for the trajectory streaming.
May be used to synchronize the internal position streaming clock to an external clock signal.
StreamBaseRate must be a whole-number multiple of the external sync rate.

Value is ony used when trigger mode is set to external sync ( = 2).
