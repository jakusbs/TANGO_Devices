    SmarActMCS2Ctrl Class Description :

      Controller device server for MCS2 Smaract Control System.

      Commands / attributes of this class should never be called directly,
      they are meant to be called from the SmarActMCS2Motor devices.

      If your controller is equipped with an IO module, you will see
      an additional attribute:

      IoModuleOutputVoltage:
      This attribute specifies the IO module output voltage for the digital outputs.
      Valid value are:
      0: 3V
      1: 5V
