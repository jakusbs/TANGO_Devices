Command GetPositionKnown :
    Finds out whether the physical position of this axis is known.
    If false and the motor has an encoder with reference mark,
    run command `Home`.



GetPositionKnown Definition
Input Argument Tango::DEV_ULONG axis number
Output Argument Tango::DEV_BOOLEAN true: physical position is known
false: physical position is not known
