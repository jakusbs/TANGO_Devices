Command SetCalibrationOptions :
    Set calibration option (used with Calibrate command)

    bit 0: Direction
    bit 1: Detect Distance Code Inversion
    bit 2: Advanced Sensor Correction
    bit 8: Limited Travel Range

    all other bits are reserved



SetCalibrationOptions Definition
Input Argument Tango::DEVVAR_ULONGARRAY 0: axis number
1: calibration options bit field
Output Argument Tango::DEV_VOID
